# Inventory Stock-Level Analysis

## What problem does this solve?
In supply chain operations, poor visibility of stock levels leads to stockouts, 
overstocking, and wasted money. This project analyses inventory data to show 
which items are fast-moving, slow-moving, and at risk of running out.

## What data / tools did I use?
- Python, pandas, NumPy
- Jupyter Notebook / Google Colab
- Matplotlib for charts
- Sample inventory dataset (product, stock level, reorder level, sales)

## What did I do?
1. Cleaned the inventory data - removed duplicates, fixed missing values
2. Calculated stock status for each item: OK / Low Stock / Overstocked
3. Identified fast-moving vs slow-moving items
4. Created charts showing stock levels and items at risk of stockout

## What did I learn / what was the result?
- How to clean and explore real-world inventory data with pandas
- How data analysis can support better ordering decisions
- Clear reporting helps procurement and warehouse teams act faster and 
  prevent stockouts

## How to run it
1. Open `inventory_analysis.ipynb` in Jupyter or Google Colab
2. Run all cells
3. See the charts and summary table at the end
